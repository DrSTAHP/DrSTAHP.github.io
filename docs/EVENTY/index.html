Zdarzenia w JavaScript

  1. CLICK - Inkrementacja przy kliknięciu myszy.
  2. DBLCLICK - Inkrementacja przy dwukrotnym kliknięciu myszy.
  3. MOUSEOVER - Inkrementacja przy najechaniu myszą.
  4. MOUSEUP - Inkrementacja przy zwolnieniu myszy.
  5. MOUSEMOVE - Inkrementacja przy poruszeniu myszą.
  6. SELECT - Inkrementacja przy zaznaczeniu tekstu.
  7. FOCUS - Inkrementacja przy wejściu w tekst.
  8. BLUR - Inkrementacja przy wyjściu z tekstu.
  9. CHANGE - Inkrementacja przy zmianie tekstu (+enter).

W celu utworzenia zdarzeń w JavaScript, można użyć metody obiekt.addEventListener.

Oto przykład kodu zdarzenia, które będzie odpalać funkcję funkszon().

                    <...>

                    let obiekt = document.getElementById("przykladowy_obiekt"); //Uchwyt do obiektu.
                    obiekt.addEventListener("click", funkszon); //Dodanie do obiektu konkretnego zdarzenia i ustalenie callbacku.
